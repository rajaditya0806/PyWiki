# Lists

A **list** is an ordered, changeable collection of items.

## Creating a list

```python
fruits = ["apple", "banana", "cherry"]
print(fruits[0])   # apple
```

## Common operations

| Method | What it does |
|---|---|
| `append(x)` | Adds `x` to the end |
| `pop()` | Removes and returns the last item |
| `sort()` | Sorts the list in place |
